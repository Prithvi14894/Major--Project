# Multi-Disease Retinal Screening

## Dataset

The complete retinal image dataset is not included in this repository because of its large size.

[Download Retinal Dataset from Google Drive](https://drive.google.com/file/d/1oNqkC5YxA3ciV__Jpk1_CUB1zCrwmHML/view?usp=sharing)
## Project Structure

- `app.py` – Main application
- `app/` – Application/frontend files
- `notebooks/` – Jupyter notebooks
- `models/` – Trained models
- `report/` – Project report
- `datasets/` – Dataset (available through the Google Drive link)
